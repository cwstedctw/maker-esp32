接球網頁遊戲：用板子玩

這個瀏覽器不能連板子。 網頁連 USB 用的是瀏覽器的 Web Serial 功能，只有電腦版的 Chrome 或 Edge有； 手機、Safari、Firefox 都沒有。請改用電腦版 Chrome 或 Edge 打開這個檔。 沒接板子也可以先用鍵盤的方向鍵玩。
